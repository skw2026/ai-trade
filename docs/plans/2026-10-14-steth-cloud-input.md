## 固定执行顺序

1. 保留旧原件及源代码 hash，验证新采集器、加密恢复和独立审计的合成测试。
2. main 提交带 skip ci，核对精确 SHA 无自动工作流和部署。只创建两个本批
   临时 Secrets，Key与种子均走标准输入，不出现在命令参数或公开日志。
3. 唯一首次 attempt 的隔离运行，串行采集；连接15秒、总30秒、最少间隔1秒、
   零自动重试。控制值不符、未知错误或不完整立即停止，不二次 dispatch。
4. 仅密文和脱敏 hash 收据上传；取回核验运行身份、日志收据、保留期、密文
   及明文 hash，解密和合并只在本机。无目录解包，不跟随用户提供的路径。
5. 删除本批新 Secrets，并核对既有 Secrets 名称集合未变。完整52点输入
   准入后才执行原冻结成本计算一次，再从原始 ABI 独立复算全部报告数值。

结果只回答固定样点的赎回折价是否覆盖参考成本预算。即使存在空间，也不
代表成交、赎回等待期风险、美元净收益、夏普或回撤通过；完整策略仍未准入。
三个预设出口均为0合格候选，G4未达成。任一门禁失败停止依赖步骤，继续
只读诊断及凭据安全清理；不借恢复工程增加第二次经济尝试。
