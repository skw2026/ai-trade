# BTC老龄输出支出：快速方向实验

状态：**完整开发提案，尚未执行；新链上输入尚未验收。** 本轮两机制评审
选出这一项进入方案设计，不表示已有盈利候选。用户要求的“实验阶段更积极、
先证明方向再打磨”在这里落实为：先交付一次成本后经济判断，不先建设在线
学习平台、不要求基线盈利，不预支长期观察期。实际市场批次仍待接受完整范围。

## 为什么值得做这一次

假设：老龄BTC输出重新被支出，包含不同于近期价格变化的持有人行为信息；
其对之后72小时价格的关联，可能覆盖一次低频交易的全部成本。相反解释是
钱包整理、自转账、价格波动引发转账，或关系已被市场吸收。支出不是卖出，
本实验不使用交易所地址标签，不预设“旧币移动必跌”。

币龄与支出量可以从UTXO创建和花费记录定义，而不是从后来价格反推。
[原始队列研究](https://www.nature.com/articles/s41597-022-01254-0)提供这种
测量方法；它不证明本项目策略可盈利。[OBM作者仓库](https://github.com/diegorllanos/open-bitcoin-metrics)
提供公开指标定义和代码。155日阈值来自选定指标的定义，不在本批调整。
这不同于已关闭的价格反转、矿工调难卖压、ETH供给或ETH/SOL价差路线。

## 冻结学习与对照

2021-01-11至2021-12-30（左闭右开，353日）为训练选择域；2025-01-13至
2026-01-01（同为353日）为冻结开发评价域，之前价格仅作预热。两年均已用于
本项目历史研究，**都不是新独立确认集**。没有2022—2024连续资金轨迹，
2025是新初始参考账户，不能拼接为2021—2025实盘净值。2021触线的候选不可
借2025重置复活。单个域内不按月/季度重置资金、回撤、仓位或风险锁存。

每个UTC日T只做一次新仓决策：

1. `x_d = old_d / total_d`，最新可用日为`d=T−3日`。用此前28日（不含d）
   的均值和总体标准差计算`z=(x_d−mean)/sd`，截到[-3,3]；sd小于1e-6不开仓。
2. `r = clip(log(P_T/P_(T−7日))/0.05, −3, 3)`；P是截止该时点最后一个
   已闭合5分钟trade close，不读取决策后bar。0.05是事前尺度，不从评价域拟合。
3. 评分`s = a*z + b*r`；空仓且`|s| ≥ h`时按s符号开多/空，非空仓不加仓。
   每次开仓后只按最长72小时、硬风险或数据/执行故障退出，不按信号每天翻仓。

价格消融对照只使用r，不因未使用的z标准差过小而停仓；全局输入完整性仍须
通过。多头持有对照在评价域首次执行时按同样2,500名义建仓，数量固定，
仅期末/硬风险退出，不适用72小时退出；它是被动暴露诊断，不参与训练选择。

训练向量固定为`a∈{-1,1}, b∈{-1,0,1}, h∈{1,2}`，共12个；固定机制对照
为`(-1,0,1)`。另训练4个**价格信息消融对照**：`a=0,b∈{-1,1},h∈{1,2}`，
不重开旧价格路线的资格，只用于判断新信息是否有价值。两组分别选择2021
`min(基础净损益,压力净损益)`最大的未硬停止路径，负收益也可参与选择。
平手（1e-6 USDT内）优先基础加压力两账总成交名义额低者，再按(a,b,h)字典序。
任一选择组全无可选路径则`NO_GO_RISK`，不新增第17向量。空仓0收益不能判成功。
固定机制若在训练已硬停止，2025对照保持禁开仓、评价增量记0并明确不活跃，
不能重启它制造完整交易覆盖；候选对它的增益不替代对未停止价格对照的增益。

冻结全部模型、预处理、源码、输入和选择结果后，只评价6条路径：胜出机制、
固定机制、胜出价格对照、同资本25%名义多头持有对照，以及胜出机制的两条
预定敏感性路径。后两条分别为链上可用时点再延迟24小时、所有成交再延迟
5分钟；其余规则不变，不重新选择。所有路径均有基础/压力两账和同一硬风险。
若两个身份相同允许共享计算，报告须保留各自身份。无随机种子择优、第二名
补跑、窗口重选、事后特征扩充或在线调权；这检验有限离线学习，不冒称自进化。

## 完整参考执行账

每条路径初始10,000参考USDT，每次目标名义2,500，数量向下取0.001 BTC，
价格按0.1 USDT不利tick取整。总名义上限5,000；不再平衡。以下均为研究
假设，**不是已核实的历史盘口、当前账户费率或真实强平价**。

- 决策/退出请求后5分钟尝试成交。基础价为该5m bar open再加买/卖不利2bps，
  手续费5.5bps；压力买用high、卖用low，再加4bps，手续费11bps。不是对
  理想利润简单打折。额外5分钟敏感性只改变执行时点。
- 单bar最多使用成交量1%，向下取步长；这只是容量拒绝上界，不证明能成交。
  不足全量时记录实际部分、取消剩余新仓，按退出规则撤回。零成交不记完整周期。
- 普通期限从首笔实际入场起计72小时；退出请求后每5分钟继续处理剩余仓位，
  至请求后30分钟（含）为最后尝试。仍有残余即执行不足，不假平仓。
- 使用CSV绑定的真实资金费时点与费率，按当时持仓和mark open扣/收；同一
  时点先结资金费，再成交。必须回到原响应验证CSV字段语义，不能把8小时
  费率每5分钟重复收取。资金费不随压力倍增，允许收入为负费用。
- 硬风险每5m bar检查。按该bar对持仓不利mark extreme与上次已知峰值检验
  8%回撤，再用mark close更新峰值；明确不假定bar内极值顺序。触线于bar
  闭合时请求退出，基础/压力任一触线就共同永久停止新增风险，照常支付退出成本。
  最大回撤同时报告close口径与不利极值口径，8%不是最大实际损失保证。
- 每次开仓按1倍入场名义额分配参考逐仓抵押。参考剩余抵押=抵押+未实现损益
  −累计该仓费用/资金费−压力退出储备；不利mark下低于当前仓位名义8%即停止。
  真实维持保证金档位未知，禁止把参考缓冲称为认证的清算距离。抵押耗尽也停止。
- 期末前72小时30分钟不开新仓，最后30分钟无条件退出；训练在2021-12-30前
  平仓，评价在2026-01-01前平仓，不借用边界外价格或删掉失败退出。已请求
  退出的同日不开新仓，正常决策只在下一UTC日且已空仓后恢复。

净损益必须可逐笔复算：`毛价格损益−滑点−手续费−资金费`。毛损益按相同
数量/时点的未加成本open计算，压力high/low及tick影响全部进入滑点，避免
重复扣费；可清算权益另减压力退出储备（11+4bps），实际退出时不能再重复扣。
每笔、每次资金费、部分成交及残余退出都输出账；另用Decimal独立实现复算。

新离线路径连续两个完整UTC周净损失只报性能告警并核对输入/账务/状态；
模型更新本来就冻结。未知数据/执行故障停止新增风险，硬风险永久停止。
这仅是本提案的性能语义，不修改旧Safety、8/12/20产品规则、旧失败或Demo禁开仓。

这些是本批开发投入标准，不是统计功效承诺或旧门槛降级：

| 判断 | 冻结条件 |

| 输入/账务/退出 | 完整、可独立复算，所有候选评价路径期末无残余 |
| 风险 | 胜出机制及两条敏感性基础/压力均未触发硬停止 |
| 绝对价值 | 2025常规基础净收益>0、压力净收益≥初始资本2%（200） |
| 新信息增益 | 常规两账分别比胜出价格对照至少多初始资本0.5%（50） |
| 学习增益 | 胜出机制不同于固定机制时，两账还须分别多于固定机制至少50；相同仅标固定机制支持 |
| 分布 | Jan13—Jul1与Jul1—Jan1两段压力损益都正，保留同一连续账；至少12完整周期、8个实际持仓UTC周 |
| 集中度 | 最大单周期和单周正净损益各不超过对应全部正净损益35%，去掉最好一周的账务压力总损益仍正 |

顺序裁决：输入/执行不完整为`INSUFFICIENT`；已确定硬风险同时具名报告，
不能被缺件掩盖。完整证据下硬风险为`NO_GO_RISK`；收益/增益/分段/延迟不合格
为`NO_GO_ECONOMIC`；正收益但事件/集中度不足为`INSUFFICIENT_DIVERSITY`；
全部满足才是`DEVELOPMENT_SUPPORTED`。旧路线与不合格候选数量不被重写。

报告同时列毛/净、两类回撤、全部成本、换手、成交/失败数、敞口时间、方向
暴露与买持对照，避免把低风险敞口少亏称alpha。日收益保留空仓日，给普通
365日年化夏普及Newey–West日滞后7长期方差口径；方差无效或硬停不给可信
夏普。既往多轮研究和本批16次选择均披露，不用开发p值或高夏普宣称独立盈利。

## 正向之后才打磨什么

开发支持只意味着“该新信息值得下一笔工程投入”，不是G4或未来必赚。届时
先冻结唯一模型，接入带实际接收时间的影子采集，校准同样成本/延迟/退出语义，
再提交一个有明确终点的独立验证范围。真实成交证据、独立统计资格和在线学习
增益不能省略，但不再作为本次方向试验的无限前置工程。

确认投入以实际开发周净损益的相关性、方差、尾部和事件频率估计，报告
5%单侧误放行/80%联合功效目标所需样本及假设，并比较可承担的上限；当前
真实效应/功效/期限均UNKNOWN，不预设两周或半年。没有可承担独立出口就保留
开发发现并停止投入。普通继续不解除人工禁开仓，也不自动启动新预算。
