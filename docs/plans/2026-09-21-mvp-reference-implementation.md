## 模型的金融含义

2x、1% MMR、13bps 平仓负债预留、单一 10,000 mark 名义参考档位、0.001 数量步长/最小量、5 最小开仓额、0.1 价格 tick 均为**明确的参考假设**，不声称等于 Bybit 历史或当前账户规则，也不声称在所有路径上收益更保守。初始模拟资金 10,000，策略参数及 3,000 gross/1,000 每单名义上限、8/12/20% 风控不变。

独立参考抵押余额 B：加仓将成交名义/2 从自由现金预留并从 B 扣入场费；资金费从 B 扣除（负值收入增加 B），不自动使用其他现金补仓。减仓按剩余数量同比释放 B，已实现盈亏和退出费进入自由现金；总账费用与 funding 只计一次。自由现金为账本 cash 减 B，负值停止。边界解 `B+q*(m-entry)=abs(q)*m*(0.01+0.0013)`，只输出带 reference 来源的风险距离，**不写入 AccountState 的交易所 liqPrice**。不能解决的缺失/非法数值/档位越界拒绝，不填默认安全值。

上述资产负债等式是本合同定义，不冒充 Bybit 官方逐项算法。官方一手依据只用于区分逐仓、mark 触发与保证金结构：[逐仓与强平](https://www.bybit.com/en/help-center/article/UTA-Trading-Rules-Liquidation-Process)、[初始保证金](https://www.bybit.com/en/help-center/article/Initial-Margin-USDT-Contract)。官方公式、费用处理、动态档位可能不同，本参考模型不补发账户资格。

## 数据与不可识别路径

只实现本地 raw JSON→CSV 的严格转换，要求请求范围、响应身份/哈希、完全闭合连续 5m trade/mark、完整 observed 8h funding grid。该 grid 是固定 BTC 参考适用条件，发现其他间隔/漏页即不足，不断言所有合约永远 8h。不存在的事件只在完整覆盖确认后填 0；禁止 hourly 插值。参考区间固定为 2025 年（前置一天预热，末端延长至 2026-01-01 00:05 以计入 00:00 funding）；不能称未见 OOS。

开盘事件不携带未来 mark 高低；闭合时才检查持有期 mark 高低。若期间可能进入 8% DD 控制或小于 8% 强平距离，而分钟内控制顺序不可重建，则立即 `INSUFFICIENT`，不猜测补成交。已观测的维护保证金破产边界给 reference REJECT。funding 用 mark_open，按旧持仓记录高低区间误差上界；该误差可能改变裁决时不足。终端撤单、付费用平仓，尘埃不得免除损失或伪装全平。

## 一次总体验收

必须同时覆盖：

1. 多空入场/加仓/加权成本、资金占用、部分和全部平仓、fee/funding 不重计、禁止补保证金、已知与未知风险、超档位、拒绝穿仓反手、非有限与陈旧输入。
2. 参考风险接入原 TradeSystem 与应用闭环，原模式 unknown 仍拒绝加仓；禁止私有同步/人工周期补签覆盖本次筛查；pending 不重复释放资本。
3. 数量向下量化、价格不利 tick、最小订单、减少不扩大、末端尘埃、跳空实际成交后的资金限额检查；不保证成交前报价可预测跳空。
4. 完整 raw 证明、重复/断档/错 symbol/错接口/未闭合/缺 funding/篡改哈希/未来泄漏/末端边界，正负合成输入均断言。
5. 三态裁决：风险优先，证据不足不升级，部分成交去重计活跃度，完整 UTC 日及半年度净收益要求，base/stress 都过才是值得再验证，不是盈利或 Demo 资格。
6. 定向和全量回归，当前文件身份归档；旧失败证据不改写。新模块只跑合成，不能借测试运行历史收益。

任何非预期正式验证失败先暂停并按门禁复盘，一次原命令复验；连续两次未解决或结构不可达重审路线。到限未通过即停止，不追加补丁周期。通过只代表可以申请一次历史额度，行情仍未取得、经济资格仍未通过。
