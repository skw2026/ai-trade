# 离线自学习闭环验收（事前冻结）

用户在目标对齐后明确要求自动按计划落地。本阶段预算为 16 个有效工程小时
（缺口确认 4、真实学习链路 8、负例/回滚/交付 4），不自动续期。开始于
2026-09-22；原工程封版已完成，旧研究和旧耦合工程 HALTED 保持。
独立状态 `.artifacts/offline-learning-loop-20260922/validation-state.json`
仅属于本次明确批准的新离线工程阶段，不是原研究的 retry 或 reset。

## 目标与证据边界

保留多币种、Miner、Integrator、受控自适应和自主闭环的产品目标。
当前缺口是同一真实训练产物贯通组件的离线证明，不是再找一个市场策略。
已有 oracle 正例是评分函数测试，已有事务测试证明门禁/回滚逻辑；均保留，
但不冒充真实学习证据。复用生产组件，只新增隔离的验收驱动和回归。

本阶段采用生成器已知、特征在决策时可得的合成 OHLCV：当前成交量信号影响
两个 bar 后的收益；训练只读取 development，至少一个 bar 执行延迟，独立
未来窗口只作验收。噪声、训练标签打乱、过高交易成本、关系反转事前固定。
不使用 oracle 方向直接代替学习，不用手工填写通过报告代替计算。

真实 C++ Miner → 生产 Python 特征/训练函数及 CatBoost → 保存模型 →
生产 C++ Integrator 推理/策略政策 → 风控/执行意图/模拟成交账 →
生产 SelfEvolutionController 的受限更新和回滚。所有成交是测试驱动的
离线假设，不是交易所撮合或 Demo 成交。线上晋升仍须原闭环契约全部证据。

合成产物标记 TEST_ONLY、经济/交易/晋升权限均 false；不写生产注册表。
离线推理使用已有非接管加载模式，同时断言 strict 接管拒绝合成报告。
不伪造 Bybit 来源或 governance.pass，不修改生产治理门槛来接纳测试数据。
本阶段通过只代表这条离线组合链路，不等于完整 MECHANISM_VALID、
ECONOMICS_VALID、LIVE_VALID、自适应在市场中有效或项目整体通过。

## 固定验收

- 固定随机种子和一次训练配置；一个真实模型及一个标签打乱对照，不调参搜索。
- Miner/特征变换/模型仅使用训练域；标签 t+2 与特征 t 分离，训练尾部 purge。
- 已知可学习正例：独立未来窗口至少 80 个不重叠平仓 episode，成本后均值及
  95% 均值置信下界为正；与固定方向对照比较，不称为市场统计证据。
- Python/C++ 同模型同特征推理一致（概率最大绝对差 <=1e-5），有真实模型驱动
  的非零提案、执行意图和模拟平仓；期末空仓且现金/损益/费用一致。
- 噪声、打乱标签和成本负例不获得离线正例资格；关系反转产生亏损反馈，
  原控制器按连续两次劣化回滚、冷却期不更新；权重上限/步长持续断言。
- 缺模型、错误候选身份、缺失/过时输入和硬风控拒绝不得产生可执行新增仓位。
- 复现命令、生成器/模型/报告/二进制 hashes 留档；相同输入重放结果一致。
- 原研究 gate、风险配置、候选关闭状态和研究调度不变。

## 执行与失败出口

优先复用本地已有镜像，断网、无凭据、临时容器、只挂本仓库及本阶段产物。
正式构建/验收均经本阶段 gate；预期负例在测试内断言，不掩盖意外失败。
失败立即暂停依赖，诊断后限定修复；复盘被原 gate 接受才一次原命令 retry。
重复失败或结构性不可达重审路线，预算耗尽按失败/证据不足结案，不换名字续跑。

通过后按既有 main/CI/CD 授权交付测试代码；不改交易配置、不恢复研究 cron。
本批没有新市场数据下载、市场回测、账户查询、候选激活或下单。
需要新市场经济研究时仍须具备新依据、可达数据与独立预算，不自动接续旧失败。
