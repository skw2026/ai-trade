# 尾部预留资金与资本效率裁决

接续圆桌已确定的下一步，回答原10000USDT参考预算能否容纳既定终端风险
所需保证金，以及条件正现金最多能支付多少资本成本。不是新行情实验，
不改变收益原件、不放宽执行资格，也不把6%敏感性变成新准入门槛。

2026-10-18 17:05 UTC至17:35 UTC，最多30工程分钟、1次解析批次、0新增
网络/行情/账户/订单/训练/等待。固定上一批同T120、八期、288格及全部
成本/规模/期限/原现金；不筛选期限、不优化杠杆或再选参数。

沿用原参考维护安全系数0.10、最大终端指数2倍现货mid、交割费最坏0.0005。
每个期限事前固定同一个USDT保证金数额，覆盖两种成本及全部终端情景，
不能事后按涨跌情景变更。有限域的最低参考需求为：

    M_req = max_cost max(0, q × ((1 + 0.10 + 0.0005) × I_max − F_entry))
    M_fixed = max(M_req, max_cost 原M)

每格追加M_fixed−原M，不能使用现货浮盈或把原独立现金费用缓冲重复算为
保证金。新资本占用=原占用+追加；原现金利润逐格完全不变。重新计算
参考终端余量、10000预算剩余、6%/12%占用机会成本及资本盈亏平衡简单
年率=现金/(新占用×原剩余天数/365)。该折算不是预期收益率或实测夏普率。

M_req只是终端不等式的解析下界，最坏格可恰为零，没有额外安全垫或实际
交易所保证金认证。I_max不是期间mark上界；完整路径、8%停止、成交与
真实账户费率仍未核实。旧时钟不足、候选0/G4未过/Demo锁保持。

按三类出口结案：预算装不下则当前规模资金结构不成立；装得下但资本
空间薄则记录“参考缺口可修、效率仍薄”并停止本地报价/收益优化；若有
值得验证的余量，也不再扩本地算术，下一缺件才是实际执行/完整路径与
独立事件。不能用小型工程连续替代这些经济缺件。

独立Fraction复算全部终端不等式、固定资金/原现金不变及所有摘要，合成
包含超预算、已有充足保证金、同一资金覆盖全部情景、非零篡改负例。
有限小数钱值严格相等，只有非终止比例计算采用具名数值精度比较。
