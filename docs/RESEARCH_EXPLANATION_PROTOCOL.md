# 研究解释能力与分层归因规则

2026年10月16日用户要求及时调整，提升实验解释能力。本规则补充既有
[产品与研究规则](RESEARCH_PRODUCT_POLICY.md)，用于之后的新设计和明确
授权的诊断，不改写旧合同或失败，不解除任何账户、风险或研究关闭状态。

## 先声明需要区分的解释

每个新范围至少给出一个经济假设和一个竞争解释，以及什么观测能区分它们。
输入完整只是可研究条件，不等于收益机制成立；研究进入不要求先证明盈利。
不用“指标可能有用”代替可检验问题，不把数据可下载作为唯一优先级。

方向、信息可用时点、作用期限、交易期限、仓位和费用分别声明。固定期限
是一个待检验设计，不是所有指标通用的自然规律。若信息在可用前消失，应
标不可交易，不通过提前时间戳或忽略发布修订恢复优势。

## 信息预测与交易收益分开

新增信息采用配对比较：相同日期、标签、训练与评价时钟、模型预算和尺度
估计下比较既有信息与新增信息。缺失输入同时排除双方，不把基准全样本和
候选子样本比较当增量。预处理只用训练集，跨边界未成熟标签不得用于训练。
持有期标签重叠、时间依赖、正则化效果和多次选择必须进入解释。

预测误差改善、回归系数、相关性和扰动对照均不是收益或因果证明。相关
冗余特征也可能通过改变岭回归有效惩罚改善误差；对此必须保留负控制或
解释限制。单次扰动不是随机化检验，描述性标准误不是独立确认的置信保证。
不能以一次低自由度模型没有增量否定所有预测函数。

交易层继续使用完整成本、持仓继承、风险与退出约束。分别报告毛价格损益、
成本、风险路径和时点敏感性，不把不同暴露的净收益差直接叫alpha。新增
收益实验须在完整新范围内冻结；信息诊断不能隐式启动交易或复活硬停路径。

## 统一报告六层状态

| 层 | 需回答的问题 | 不允许的替代结论 |
| --- | --- | --- |
| 输入 | 身份、时点与缺失是否可知 | hash一致等于历史首发认证 |
| 信息 | 配对预测是否改善，是否稳定，误差多大 | MSE改善等于净收益或因果alpha |
| 政策 | 动作、期限和仓位是否匹配信息与目标 | 单个模板失败等于全部机制无效 |
| 经济与风险 | 全成本后的收益和路径是否满足合同 | 缩小仓位活过停止线等于发现优势 |
| 执行 | 同一政策能否按同一时钟和账务实现 | 合成通过等于真实成交可实现 |
| 确认 | 独立来源、样本量与总成本是否可承担 | 新切分已见历史等于独立确认 |

尚未测量的层写NOT_EVALUATED或UNKNOWN，不填零或PASS。报告必须说明本次
结果排除了什么、仍不能区分什么，以及为什么下一项工作有识别价值。
工程通过数和审计数量只放工程段，不折算为经济进度或G4完成比例。

## 全项目选择与有限结束

同一数据域跨批次使用应累计披露；新批次不重置历史选择次数或独立性。
完整范围同时冻结特征集合、期限集合、模型数量、扰动规则、终点和不足出口。
并非每次都要求同一线性模型或同一门槛，但不能看结果后扩大集合。

开发后可精算确认样本量；独立输入来源的可达性与总投入上限应在新收益
范围进入前明确。没有可承担出口时只保留开发发现，不自动采集等待。
诊断完成后的新交易政策、已关闭族重开及长期观察仍需实质完整范围；普通
继续不自动追加预算。本规则是研究设计与报告约束，不是已接入生产的门禁。
