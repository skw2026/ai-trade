## N1：有数据入口，但“哪天的数据”不等于“当时已经知道”

Lim 的[原作者摘要](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6592830)提供次日预测性的研究线索；[对应仓库 README](https://github.com/boonchuan/etf-price-impact)列明流量来自 Farside、ETF OHLCV 来自 Databento、BTC/ETH 价格来自 Binance，并称预测性到第二天衰减。仓库显示存在日度流量及合并文件，**本轮只读说明与文件目录，没有打开 CSV、运行作者程序或复现其统计值**。论文原文未取得，不称其已独立复核或已经证明因果/盈利。

[Farside 自身说明](https://farside.co.uk/page/4/)称其日度流量通常在美国晚间和夜间陆续更新。[IBIT 官方页面](https://www.ishares.com/us/products/333011/ishares-bitcoin-trust-etf)提供带 as-of 日期的份额及下载入口，并解释持仓展示口径与基金会计口径可能不同。上述资料支持“公开入口存在”，但本轮未核实逐日数值的首次发布、修订版本以及它们相对 Binance/Bybit 收益窗口的位置。

因此不能把同一个日历日期 join 后的关系直接转换成交易规则，也不能用股票 ETF 的成交价格替代 Bybit 永续执行价格。没有宣称提供方一定不存在时点档案；只是现有说明不足以认定已经获得这种证据。

**为何不先随便延迟一天回测？** 延迟可以定义新的参考情景，但是否仍保留原研究的问题、如何处理修订都必须明确；它不是历史信息可得性的证明。这里最便宜的下一证据是现成的发布/版本说明及时间对齐材料，而不是先写策略或下载几年行情。当前没有把这项缺口自动变成新的采集任务。

作者还有[另一 ETF 研究仓库](https://github.com/boonchuan/btc-etf-price-impact)，其题目、样本长度与价格来源不同。不能将两份研究的不同系数混为同一结果，也不把同一作者的不同项目当作独立复现。

## N2：宏观敏感性不直接给出公告后的可交易方向

[纽约联储研究 SR1052](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr1052.pdf)研究覆盖公告前后的短事件窗，并由公告窗内利率工具的变化构造政策意外；其 2017–2022 BTC 样本对政策路径的响应不稳健。若把包含公告后价格的信息当成公告时已知信号，就把解释变量与实际决策时钟混淆了。此文不是当前市场永远没有宏观关系的证明。

相反，[IMF WP23/163](https://www.imf.org/en/-/media/files/publications/wp/2023/english/wpiea2023163-print-pdf.pdf)支持紧缩政策与加密资产共同波动的关系；[2026 年更新的政策叙事论文摘要](https://arxiv.org/abs/2604.08825)也报告周度文本指标的预测信息。但宏观冲击研究、持续文本叙事和本轮的“预定公告后延迟重估”不是同一个信号。不能把这些结果拼成“公告出来以后按鹰鸽方向交易即可获利”的证据。

本次未取得一个在自身预测窗开始前可用、无需另造文本模型且针对公告后残余变化的固定预测对象。基于日历的可知事件时间不能替代政策意外的可知数值。裁决只是否决本次立项依据，不否认宏观因素影响 BTC。

## N3：不能把其他币种的论文结果移植成 BTC 卖压

Chi、Chu、Hao 的[原始论文](https://arxiv.org/pdf/2411.06327)明确区分净流入的资产。其 BTC 净流入对 BTC 收益的多数所考察期限没有显著预测力，4 小时例外为正向；论文的较强负向结论主要针对 ETH。不能在看到这个例外后改选 4 小时，或把 ETH/USDT 替换进已登记的 BTC 卖压对象，来凑出本批“成功候选”。这不是对所有链上因子的总体否定。

[Glassnode 官方时点文档](https://docs.glassnode.com/data/point-in-time-metrics)说明地址聚类会影响历史修订，PIT 历史取决于各指标开始记录的时间；`computed_at` 与实际 API 发布之间还有延迟。[PIT 接口索引](https://docs.glassnode.com/basic-api/endpoints/pit)的官方索引内容列有交易所净流量变体及 API key 要求，但正文读取失败，未验证本账户访问权、具体区间或费用。不将接口存在写成完整可用历史，也不凭聚合百分位延迟构造保证上界。

## 路线复核与停止条件

- **目标对齐：** 本轮找的是“实际可知信息能否带来后续净优势”的有限研究依据，不是相关性、解释力或更多代码。原 PRD 的风险覆盖与 H1 固定名义暴露不同，但不能因此默认重开 H1 或宣称风控会创造 alpha。
- **数据可得：** 新发现的 ETF 作者数据目录和链上 PIT 入口有复用价值；没有再笼统声称“外部历史拿不到”。关键未证实项是信息何时可用、怎样修订，以及信号是否就是论文实际研究的对象。
- **方法可达：** 参考模型可以声明假设，不需要先完成账户历史认证；但不能用未说明的未来信息定义一个根本无法在当时执行的信号。三条路线均不因补更多成本小数位或增加模型复杂度而自动变得成立。
- **预算与出口：** 只评审固定三项，选用下列 12 项一手资料后停止扩源；没有第四项、实验合同或候选注册。0 条入选是批准范围内的终态，不开启默认 WAIT 时钟。

未来若用户决定重新投入，必须带来改变本次判断的材料，而不只是再次说“继续找”：N1 需要可审计的发布/版本时间及与预测窗的对应；N2 需要明确支持公告后可交易延续的依据及因果可得的意外指标；N3 需要支持指定 BTC 机制的独立依据与适用区间内的时点来源。以上是再入条件，不是已批准的补证任务、供应商联络或数据采购。
