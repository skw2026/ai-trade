# 资金成本语义取证与下一步决定

已经确认：6%/12%是10月17日引入的开发假设，不是当前产品规则指定的
最低年化收益，也没有绑定实际账户融资凭据。旧研究实现把这一机会成本
同时用于入场、净值、8%回撤停止和下一季度本金。它按原合同进行了正确
的算术计算，但其结果是**扣除假设资金基准后的经济效用账**，不能直接
当成自有资金账户的现金与可清算净权益。

本轮完成来源追溯及固定合成取证，没有修改旧模型、降低旧门槛或重跑真实
行情。下一步需要一次实质口径决定：是否为后续新实验分开账户账与资金
基准账。现有经济否定、风险UNKNOWN、G4未达成和Demo禁开仓均保留。

## 6%与12%的来源已经追溯

[原七日计划](../plans/2026-10-17-dated-basis-assumption-screen.md)在
`d2d949c9`引入这两个数字，并明确整张费率表都是事前研究假设。Git历史
核对该计划只有这次引入，当前正文与该提交一致；随后三期限和容量诊断
沿用了它，没有新的实际融资事实为其赋值。

当前[产品规则](../RESEARCH_PRODUCT_POLICY.md)要求基础与压力净收益为正、
独立经济确认和同策略执行，但没有规定6%/12%资金基准。旧PRD中的12%
是账户回撤减仓阈值，不是利率；旧净收益定义列的是手续费、滑点和资金
费率。这个来源差别不能靠相同数字混同。没有访问账户，实际是否借款和
实际融资费率仍UNKNOWN，不能据此宣称用户真实融资费用为0。

机会成本本身并非错误。经济评价可以扣除自有资本的机会成本，正的账面
收益不必然表示超过资本所要求的回报；但这与已支付利息不是同一个概念。
[CFA剩余收益说明](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/residual-income-valuation)
区分了债务利息与权益资本机会成本；[CFA经济利润定义](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/firm-market-structures)
也明确经济成本包含机会成本。这些概念不能替本项目证明具体6%或12%的
取值，更不能把“不是实际支出”直接推成“可以不要求经济优势”。

## 一项假设影响了五处判断

静态取证覆盖未修改的[三期限引擎](../../tools/dated_basis_term_screen.py)
和原七日实现，Decimal审计也复现同一语义。

| 位置 | 当前实现 | 影响 |
| --- | --- | --- |
| 入场预测 | 预计回款减显式摩擦再减机会成本 | 决定是否入场 |
| 持仓估值 | 可清算价值减累计机会成本 | 形成经济效用净值 |
| 8%回撤 | 用上述净值更新峰值与回撤 | 可触发退出 |
| 期末本金 | 现金余额与卖币回款再减机会成本 | 小于同路径现金余额 |
| 季度继承 | 下一季度继承上述期末本金与峰值 | 机会成本继续影响资金和风险状态 |

同一持仓状态的BTC保证金权益公式没有直接扣机会成本，不能笼统说保证金
分支也被同样扣减。退出时间改变仍会间接改变后续路径。上述逻辑属于离线
研究模型，本轮没有发现或修复生产C++账户系统中的同类问题。

## 合成现场验证了什么

固定控制使用10000参考本金、特意构造的10800历史峰值、90日持有域，
现货恒100、期货与mark恒104、结算100。保留压力手续费、滑点、维护
保证金与8%阈值，强制建仓只用于检测语义，不是某条合格策略。

| 固定控制 | 结果 |
| --- | --- |
| 旧12%机会成本进入权益 | 约50.38日后累计39.97664机会成本，模型回撤8.00000668%，触发停止 |
| 同一路径的可清算现金权益 | 9975.97592，对10800峰值回撤7.62985261%，尚未达到8% |
| 仅合成对照的机会成本设0 | 交易费和滑点仍在，未触线，运行至预定到期 |
| 上述对照发生真实现货冲击 | 原8%风控仍退出，回撤14.2672%；分离机会成本不消除真实损失 |
| 无基差、机会成本0 | 交易摩擦后仍亏22.49752；去机会成本不自动产生优势 |

独立现金闭式公式求出的首次触线bar及下一bar退出，与原引擎和40位Decimal
回放一致。临时情景只存在于合成进程内，调用后原常量恢复，旧文件hash
保持。所有合成金额都不是用户账户数据或市场收益。

这证明经济效用回撤与真实净权益回撤不能直接互换，不证明取消基准会让
真实策略合格。上一批2023三期限路径本来就没有8%硬停，仍存在费用、终端
转换、单季度集中和未知执行风险，不能把那些失败全部归咎于本例。

## 建议的下一范围与实质决定

建议后续新研究采用两账分离，而不是直接把费用表的6%/12%改成0：

- 账户账包含成交、手续费、滑点、实际或明确建模的融资利息/资金费、
  应计真实负债与持仓估值。本金继承、保证金和8%硬停止使用这套净权益。
- 资金基准账另计机会成本与超额收益。6%/12%继续完整披露为敏感性，
  不能冒充实际扣款；若要作为资格硬门槛，需要明确可比较基准和要求。
- 开发阶段分别判定“压力显式成本后现金优势”和“超过资金基准”。前者
  成立不自动代表经济总目标、独立确认或G4成立；后者仍须有依据的基准。

这会改变后续新实验的入场与风险权益语义，不属于普通代码修补，需要
用户确认一次。建议选择：**同意新实验分账，6%/12%保留敏感性，不再作为
开发入场的固定否决项；独立经济资格另行明确有依据的基准。**
另一选择是继续要求开发策略覆盖原6%/12%门槛；那就保持当前路线无可观测
压力机会的裁决，不再在同一输入域内做持有至交割的收益优化。

确认分账后，下一批应整体交付，最多8工程小时：先完成现金/基准独立账、
原8%风险及继承一致性，再冻结一个机会驱动政策、固定对照和总选择次数；
只有可承担的独立出口明确才启动最多一次开发市场实验。不能把已见2023
重新洗为确认，不能因分账后现金正就跳过终端风险和未知执行资格；出口
仍不可达则停止，不追加模型或默认等待半年。具体政策与确认终点尚未
冻结，因此本报告不授权立即运行新的收益实验或改变任何线上风控。
