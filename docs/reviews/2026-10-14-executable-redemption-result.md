## 成本必须沿完整现金流计算

同一基准为USDT出发、最终回到USDT，期间包括现货、链上资产及对冲保证金。
以下是需核算的交易腿，不是已实现的下单方案；顺序和对冲量仍需冻结。

| 环节 | 需要入账的量 | 当前缺口 |
| --- | --- | --- |
| USDT买ETH，建立空头对冲 | 两腿实际成交额、成交价和各自费率 | 未查询账户费率；没有同一执行时钟 |
| ETH提到链上 | 实际到账量、平台扣费、到账时间、在途敞口 | 未绑定平台规则与历史可用性 |
| Curve买stETH | 实际输入／输出、价格冲击、交易gas | 原`get_dy`是报价，不是成交；按报价定义计费，不能重复扣池费 |
| 授权与赎回申请 | allowance或permit路径、gas、实际锁入量及请求ID | 未绑定交易实现及逐笔gas；授权不必每次重复 |
| 等待finalization | 资金占用、实际等待、赎回损失、对冲资金费和保证金 | 不能预填固定等待时间或稳定1:1兑现 |
| 领取ETH | 实际可领量、claim交易gas、链状态 | finalize不等于钱已到账 |
| ETH回交易所、卖为USDT、结束对冲 | 转移扣费、时延、现货与合约成交、尾差 | 没有完整退出和同步对账输入 |
| 异常处置 | 失败交易费用、未结算请求权估值及紧急退出 | 未核实NFT买方、深度及价格 |

Bybit官方提供账户费率查询接口，但它需要签名；文档示例费率、公开VIP表
和现有程序的预算都不是本账户、本时点的成交费率。本轮不需要索取新Key：
即使费率补齐，下面的退出与资产账务缺口仍在。[官方账户费率接口](https://bybit-exchange.github.io/docs/v5/account/fee-rate)

单次固定对冲、无中途调整的简化闭环账为：

`净损益 = R×S_T − X×S_0 + H×(F_0−F_T) + 实收资金费 − 交易费 − gas/转移费 − 融资成本`

其中X为初始取得ETH，R为最终可出售ETH，H为空头ETH数量；S/F分别是两腿
实际成交价。改变对冲量须改用逐笔现金账，不套此简式。报价已含的费用不
重复扣；转移损耗计在实际数量后也不再扣一遍。gas按每笔实际消耗和当时
计价入账。收益分母包含本金、独立保证金和费用储备，不能只除以保证金。
已有ETH库存可省某次兑换，但初始市值和占用资本不能归零。

## 退出状态是本轮决定性缺口

| 状态 | 实际持有 | 能做什么，不能假设什么 |
| --- | --- | --- |
| 申请前 | stETH | 可尝试市场卖出，仍须有可执行价格与数量 |
| 已申请、未finalize | unstETH NFT请求权 | 不能撤销；尚不能领取ETH；能转让不证明有买方 |
| 已finalize、未claim | 已预留ETH的请求权 | 仍需完成领取，不是交易所现金 |
| 已claim | 钱包ETH | 尚需转移／卖出，并协调余下对冲 |

官方文档明确请求不能取消，finalization受可用ETH和协议状态制约；不能
把常态时延当最长时延。NFT转让只是可能的二级退出基础，并不提供买价
或保证成交。[Lido提款处理规则](https://docs.lido.fi/guides/oracle-spec/accounting-oracle/)
排队期间不能按普通持币计入质押奖励，兑现还可能承担协议损失；本轮仅核
当前文档语义，未完成2024历史合约版本绑定。[提款队列接口](https://docs.lido.fi/contracts/withdrawal-queue-erc721/)

这与原产品风险动作存在未解决的兼容问题，而非已证明的普遍软件bug：

- [产品要求](../需求描述.md)为8%降档、12%强制减仓／冷却、20%经济意义全平；
  研究8%停止是另一个规则。停止模拟不代表真实资产已卖掉。
- [风险实现](../../src/risk/risk_engine.cpp)在冷却／熔断时给单symbol目标归零。
  将空头归零不能解除NFT锁定；若仍拥有请求权，还可能增加ETH净方向风险。
- [资产账](../../src/oms/account_state.h)与[适配接口](../../src/exchange/exchange_adapter.h)
  没有请求ID、finalization、claim、链上交易确认或跨场所统一资产退出语义。
  现有现金加持仓浮盈账不能直接证明链上请求权已经计入权益及回撤。

例如持有1 ETH等值请求权并做空1 ETH，仅在面值不变、基差不变等理想假设
下近似方向中性，并不释放本金，也不消除罚没、流动性和保证金风险。关闭
空头后，请求权仍在，方向敞口反而变为约+1 ETH。这是账务反例，不是收益
预测。小额分批能限制资本暴露，但本身不满足经济全平，也不能消除这些语义缺口。

## 多视角复盘和停止决定

金融视角：折价是潜在空间，不是锁定USDT净利润；最终赎回量、两腿基差、
资金费及资本分母必须一致。风险视角：不能用可转让代替可清算，也不能把
只减仓动作机械施加到对冲腿。工程视角：需要跨资产账和状态化退出设计，
不是修改一个费率常量。统计视角：旧2024样点已见，不能重新标成独立确认；
完整独立数据和终点尚未准入，不能先学习再补资格。

因此，本轮在事前约定的不足出口关闭，不先建钱包／通用平台、不启动收益
计算、不把工程缺件说成经济否定。没有必要等35天、26周或再攒一批行情来
解决这类退出约束。现有Demo禁开仓、旧结果和旧gate保持。

再次接续的实质前提是：提出能在原风险要求下处理不可撤销请求权的可执行
退出设计；若只能接受长期锁定资产，则须明确改变产品风险范围。随后仍须
补全成本／历史结算输入和独立确认出口。这不是一次普通调参，当前不建议
为未准入路径先开发链上交易平台，也不自动改换第三机制。
