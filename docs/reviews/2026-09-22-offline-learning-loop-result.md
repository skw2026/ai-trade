## 已取得的本地证据

真实 C++ Miner → Python 生产特征/训练函数与 CatBoost → 同一序列化模型 →
C++ Integrator 推理 → 生产策略政策/风控/执行意图 → 合成成交账 →
生产自进化控制器反馈；不是 oracle 方向或手填经济通过报告。

- 正例：495 个不重叠、完整平仓 episode；独立成本后均值/95%下界为正。
- 固定模型/固定权重与自适应组采用相同预测及成本；后者实际调权 2 次，
  0.50→0.55→0.60。14 次更新决策不冒充 14 次实际权重改变。
- 噪声 491 episode、打乱标签 1 episode、高成本 495 episode 均不获得资格。
- 规律反转 742 episode，产生 2 次回滚、6 次冷却评估；上限、步长、最短
  更新间隔和冷却内禁止更新均由驱动逐次断言。
- 六组 Python/C++ 概率最大差不超过 1.12e-16（合同1e-5）。
- 六组独立逐笔重建的费用、资金费、净损益与 C++ 账匹配，终态空仓。
- 同一候选重复回放的 trace hash 相同。错身份、缺模型、缺 bar、过期输入、
  断连/未知风险/熔断新增仓位被拒绝；strict 接管始终拒绝合成报告。
- 本地完整 CTest **110/110，179.46 秒**；最终验收驱动单测 **8/8**；
  最终脚本在发布同等的断网/只读/无 capabilities/2GiB 容器中独立复现通过。

本地原始证据：`.artifacts/offline-learning-loop-20260922/acceptance/`；
最终发布配置复核：同目录 `publication-contract/result.json`。

## 两次真实失败，没有删证或改绿

1. 固定组错误读取 disabled 控制器未初始化的权重；修正为冻结常量0.5/0.5。
   [第一次复盘](2026-09-22-offline-learning-disabled-controller.json)。
2. 驱动把生产政策已带符号的金额再次乘方向，造成空头变多头。
   独立账识别错误；逐笔重算该错误行为与原 C++ 账差2.3e-13，根因已确认。
   完整路线复核后直接传递 signed notional，并增加方向一致性断言。
   [第二次及路线复盘](2026-09-22-offline-learning-signed-notional.json)。

两次修复都只改测试适配层，未改生产策略、模型超参、随机种子或验收阈值。
两次复验复用原训练模型，分别保留 retry-1 / retry-2；旧失败不覆盖。
这也暴露执行者首次接线检查不足，不能将其解释为新的市场问题。

## 自动化交付

- CTest 注册快速驱动回归，CI检查其存在；研究镜像单独携带离线驱动，
  交易 runtime 镜像不携带该二进制。
- CD 在构建研究镜像后，按不可变 digest 拉取并核对提交身份，强制执行
  `Verify Offline Learning Loop`；无网络、只读根文件系统、无账户凭据。
- 必须通过才继续部署，结果和合成证据自动归档；没有 continue-on-error。
- 本段尚未声称远端执行通过；以最终精确SHA收据更新。

## 产品目标仍未完成的部分

1. **独立小时评估未证明，而且存在实现差异。** 控制器的
   `EffectiveUpdateIntervalTicks()` 使用评估/最短更新间隔的最大值。
   本例只证明6小时更新下限，不证明每小时评估与6小时更新解耦；不得写成
   完整P0通过。这是具体后续功能缺口，不是等待样本。
2. 自适应合成收益增量包含提高仓位的影响，不是同风险归一化的市场优势。
   严格反事实 holdout 另有既有组件测试，不冒充本例已贯通该选择路径。
3. 本次调用真实训练函数，不等于生产研究调度/注册事务/真实canary已验收。
   原事务、holdout、账务、风控和回滚回归照常执行；没有合成产物生产晋升。
4. 没有合格真实市场经济候选；旧研究HALTED、旧候选关闭、旧数据失败保持。
