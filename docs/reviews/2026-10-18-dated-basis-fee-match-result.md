## 明确的经济解释

对于每笔已确认反向期货成交，令面值为N_j、价格F_j、实际BTC手续费C_j：

```
B = Σ N_j / F_j
C = Σ C_j
目标净现货 BTC = B + C
扣入场手续费后的 BTC = B + 数量舍入剩余
终端钱包 = 总面值 × (1 − 退出费率) / 终端期货价 + 数量舍入剩余
```

旧方案净现货只取B，终端另留−C BTC的尾项；新方案在入场多购买这部分
BTC，消除该项，但必须支付购币本金和现货费用。费用没有消失，只是把
随终端BTC价格变化的费用风险转为入场现金支出。

BTC买入收费时，目标毛数量还须除以(1−现货费率)再向上取整；USDT买入
收费保留为旧研究的反事实费用假设。向上取整可能留下小额正BTC，不能
宣称严格零敞口。多笔期货必须累加倒数价格和实际费用，不可用算术均价。

本轮单笔25张@50000，与两笔10张@40000、15张@60000，倒数基础及费用
恰相同，但算术加权均价52000不能产生相同基础。该对照验证账务结构，
不提供新的收益独立样本。

采用相同费用。下表为新方案减旧方案的终端现金加按终价估值的BTC零头，
不是全为已实现现金收益；两种成交拆分结果相同。

| 终端价格 | 买入费USDT反事实 | 买入费BTC |

下跌时新方案更差，上涨时更好：它减少特定负BTC风险，不是支配旧方案
的增益算法。旧盘口压力预测全部负也未因此改写，未用新数量重跑历史。

## 为什么还不能变成入场策略

目标函数只接受已经确认、费用币种已知且时间不晚于观察时点的成交。
先买现货时尚不知道后续期货实际成交价，不能用这个事后目标回写第一腿。
本轮合成路径预设全部价格以验证恒等式，明确标记`causal_strategy=false`，
不是可以照抄执行的前瞻策略。部分成交只计算已成交面值；第二腿失败时
现货风险仍在；未知费用、未来成交、重复/冲突输入均不作为新合格目标。

实际纠偏还需额外交易、费用与时间；期货先行要真实预置抵押品。终端
现货/交割指数比、手续费误差、转账到账、保证金与清算、断流、成交质量
都没有被恒等式解决。原执行诊断478组时差不可比也不能因此放宽。
