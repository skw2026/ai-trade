# 现有证据筛选结束 当前没有可启动的完整新实验

在已结束固定基差研究投入后，按[有限范围](../plans/2026-10-18-post-carry-mechanism-screen.md)
完成主审与经济、统计两个独立AI审查。结果为
`NO_EXECUTABLE_NEW_EXPERIMENT_FROM_EXISTING_EVIDENCE`，选0个完整新实验。
这不是经济学总体不可能，也不是需要再等固定天数；现有资料尚不足以
构成下一个有解释力、可执行的完整实验。

本轮没有新行情、网络、收益计算、训练、账户或部署。两个审查并非外部
专家认证或独立市场样本；它们的作用是追查历史闭合状态，避免重复立项。
筛选不必消耗满两小时，也不以多写代码或多找一个名字代替可裁决进展。

## 唯一未评价线索尚缺完整输入

BTC调整后转账量周转异常是唯一找到的具名未做经济评价的遗留线索。
[原计划](../plans/2026-10-16-data-first-mechanisms.md)明确以BTC计量实际
结算强度，区别于地址广度、手续费及老龄输出，同时承认相关性和自转账等
竞争解释。[最终结果](2026-10-16-btc-address-participation-result.md)明确：
调整后转账量不在该次固定免费文件中，未进入经济筛查。

本轮没有发现后续记录提供完整替代输入。此处的“缺”仅指已有证据包，
不是断言所有免费来源均无该字段。未调整总支出量、美元价格乘转账量或
老龄输出分母不能替代具名调整后指标；不为得到一个可跑实验混用口径。

能改变这项判断的实质证据是：

1. 具名、可实际取得的同版本`TxTfrValAdjNtv`完整开发序列，BTC单位、UTC
   日界、目标日期、缺值和取得成本明确，而非API首页或几个样例。
2. 可核的调整定义、修订和信息时钟，说明找零、自转账、重复计数如何处理。
   开发允许诚实标注重建数据，不要求研究前先有盈利证明。
3. 与旧信息的具体差异问题，以及同日期价格和旧信息消融的固定对照、完整
   成本与风险账、有限尝试和否定出口。不能只换字段再跑旧参数网格。

当前不造读取器或合成收益代替这些事实，也不通过已消费BTC历史重新取得
独立身份。以上是输入与实验可行性条件，不是向用户重新索取普通步骤授权。
