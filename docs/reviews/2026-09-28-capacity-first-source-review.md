# 新批次资料准入（取数前）

固定两项顺序R1注意力、R2燃烧供给；最多一次实验，不能用收益选路线。
R1可进入重构数据的否定性筛查；R2暂缓深入，不宣称被经济否定。

R1：[ElBahrawy等原稿](https://arxiv.org/html/1902.04517v2)明确给出日浏览量
上涨后短、下降后多，以及同形价格反转对照。其币种组合、旧样本、价格来源、
执行时钟和成本不同，本合同是独立假设，非复现。一般注意力预测研究
[Liu/Tsyvinski](https://www.nber.org/papers/w24877)不能证明此代理的方向和净利润。
这里在新数据前选择直接匹配Wikipedia的一手方法，不根据收益切换方向。

[官方API](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/reference/page-views.html)
提供2015年以来数据；user类别不是已证明的唯一自然人，重定向不归并到原页。
[维护者说明](https://lists.wikimedia.org/hyperkitty/list/analytics%40lists.wikimedia.org/thread/3VHDVLXIGIOYHOVAKPMOYKKWUMINSAUI/)
通常UTC 01–03时加载且缓存可旧4小时。本合同信号日结束后36小时入场；
这降低通常延迟泄漏，不证明历史首发版本。当时可见性未知仍阻止启用资格。
[官方事故表](https://wikitech.wikimedia.org/wiki/Data_Platform/Data_Lake/Traffic/Pageview_hourly)
披露2021-06-04至2022-01-27流量丢失，任一信号日重叠即排除，不补数。
该表不能证明其他日期无事故；当前重构结果最多提供有界否定/进一步核查线索。

信号；SSRN正文403。Coin Metrics发行字段存在执行/共识层口径差异，
不能将总手续费直接当销毁或将包含共识存款的发行直接当净新增供给。
因为固定优先的R1已具可计算独立假设，不为凑两项而采购/扩API或追加实验。
